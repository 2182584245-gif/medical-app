## 复现入口与限制

构建：`tools/build_windows_release.py --output-root <新建的外部构建目录>`。
最终 r2 使用全新目录完整重建，构建与源码/字节码验证一次通过。早期 r1 的报告编码问题
已修正；最终交付不是继续使用 r1 的旧 EXE，而是包含线程回收修复的新产物。
组装与验证入口：`packaging/assemble_demo_release.py`、`packaging/verify_demo_release.py`、
`packaging/verify_embedded_source.py`；必须使用对应的独立审核图片映射。

EXE 尚未购买代码签名，Authenticode 状态为 NotSigned。即使 Defender 此次扫描无威胁，
其他杀毒软件或 Windows SmartScreen 仍可能显示未知发布者/信誉提示，不能承诺永不误报。
GitHub Actions 运行结论以本次提交对应页面为准，不能将这份本地验收当作远端 CI 已通过。
