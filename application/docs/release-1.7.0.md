# 1.7.0 Windows 电脑版

本次只交付 Windows 10/11 64 位桌面 EXE 与完整运行目录，不制作 Android APK、手机应用
或独立网站。下载 ZIP 后完整解压，不能只取 EXE。源代码在 application 目录。

## 开发者界面

应用左上角提供“开发者模式”，需已有启用中管理者的密码与独立授予的开发权限。
普通会员、顾问以及没有开发授权的管理者不能进入。没有写死在客户端的万能密码。

1. 用户数据库：管理者、顾问、会员三表分页；双击查看个人业务资料与 AI 对话。
   允许修改明确支持的业务字段、账号名、密码重设和账号启停。密码哈希、登录令牌、
   共享密钥、主键、归属、文件路径、二进制原件与不可变审计信息不作为可编辑字段。
   大量记录通过分页读取，不提供可直接执行 SQL 的整库编辑器。
2. AI 与专业知识：模型、表达语气、复杂度、回答长度、补充提示词、只写入的 API Key、
   最多 20 项描述性技能、50 条审核专业资料、20 条每日提示。技能不是可执行代码；
   专业知识使用有来源的轻量关键词检索，不等于模型训练或千篇文献的完整向量知识库。
3. 板块与服务开放：今日记录、AI、统计、会员服务、商品、预约。新版云端另有对应
   服务端调用限制，关闭功能不伪装成数据上传成功，离线待上传资料仍保留。
4. 云服务运行设置：查看安全的实际服务状态，修改公告、联系说明、维护状态及客户端
   等待时间。不能从桌面执行任意 SSH、SQL、重启服务器、扩容或修改防火墙。

## 生效与数据保护

配置发布后，当前已打开会话保持原版本。本地下一次完整启动、云端下一次打开并登录
或退出后重新登录，加载新版本。开发者对业务资料的改动先排队，到目标用户新会话生效。
等待时若用户自己修改了同一记录，保留用户新内容并标记冲突，不静默覆盖。
账号名、密码重设、停用和顾问有效期是即时安全例外，避免过期账号无法登录恢复。
新平台后端每次启动最多处理 100 条待生效资料。

本机默认 DeepSeek Key 使用当前 Windows 用户的 DPAPI，放在发布包之外；成员聊天、
今日智能输入及顾问 AI 采用相同的默认解析入口。公开客户使用认证后的服务器代理，
不会收到服务器的共享密钥。开发者替换密钥只能写入，界面不回显原密钥。

## 预置人物

公开包保留五个虚构账号：一名管理者、两名顾问、两名会员；显示人物名称不带“示例”。
记录覆盖 2026-02-22 至 2026-09-19，共 4,632 条六类生活记录，17 个对话、72 条预写
聊天、16 条提醒、22 次服务任务、6 件虚拟商品，并包含会员状态、购物车、收藏与订单。
医疗记录只是虚构的既往事实，不是医嘱、处方或真实 AI 生成结果。
独立随机登录信息见包内 DEMO_ACCOUNTS.txt。开发者真实账号不进入公开种子库。

## 本地授权工具

仅由设备所有者在私有数据库使用：

```powershell
python tools/provision_local_developer.py --database <私有app.db路径> --username <已有管理者> --confirm-local-change
```

密码通过隐藏提示输入，不进入命令行或源码。若需新增管理者，显式使用
`--create-with-operator <已有管理者>` 并验证该管理者密码；不会静默重置已有账号。
不要把含本人密码哈希、授权或真实资料的私有数据库重新上传公开仓库。

## 云端与验收边界

既有本地／阿里云两种模式保留。旧后端没有开发者接口时，桌面显示明确升级提示，不绕过
权限。新增服务器代码与五张强制 RLS 私有表的迁移一起提交，但这不证明已部署生产。
云端上线需另行备份、隔离恢复验证、迁移、账号授权及真实接口验收。
生产运维工具的 v4 兼容边界见 [部署说明](../server/DEVELOPER_V4_UPGRADE.md)。

验收分为自动化回归、真实临时 PostgreSQL 权限检查、离屏 Qt 操作/截图、构建字节码
绑定、压缩包清单与 SHA-256、隔离启动和 Windows 安全扫描。各项结果以对应实际报告
为准；模拟 AI 测试不代表付费 AI 调用、线上部署或所有硬件/网络环境已经通过。

本次实际结果和产物 SHA256 见 [1.7.0 本地验收](release-1.7.0-validation.md)。
