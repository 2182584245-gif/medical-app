## 安全与测试边界

- 回归使用模拟传输、合成账号及隔离 SQLite，不调用真实收费模型，
  不读取正式会员资料、不写云端数据库。
- 图像与布局检查使用 Qt 离屏截图，包含小屏、大字号和时间字段滚动。
- 没有完成真实麦克风、摄像头、扬声器的硬件端到端验收；也没有模拟点击真实
  已安装程序的完整登录、聊天和退出流程。8 秒启动检查不等于完整人工验收。
- 手机/手环仍是数据适配协议，不是实际设备接入。未制作新的 Android APK。
- 没有重新验证所有地区、运营商或设备的公网连通性，也没有部署新增服务端
  顾问上下文。不能把本次源码/EXE验收解释为现网服务功能发布。
- 本包未签名。一次安全扫描无检出，不等于保证所有安全软件都不会提示信誉
  警告或误报；不要为运行程序关闭安全防护。
