# 1.6.0 电脑版合并发布说明

日期：2026-09-14。范围：Windows 电脑应用、可复制发行包及现有 Git 仓库。

## 合并来源与保留原则

- 本地已交付的 1.5.0 作为兼容性基础，先以 `062e9a2` 保存源码快照。
- 合并协作者 `d384da6`、`9914ace`，保留双方提交历史，不强制推送、不重写历史。
- SQLite 数据库结构维持第 7 版；本次不迁移生产数据库、不重新部署阿里云后端。
- 继续提供本地和阿里云模式，不恢复已停用的 Supabase 连接入口。
- 继续保留断网缓存、恢复网络后的同步、账号隔离、医疗/环境记录与统计、
  适老化界面、批量删除、时区和个人称呼等原有功能。

## 新增功能

```text
├── 日常 AI 助手
│   ├── 开启个人资料授权后，可结合有限范围内的个人生活资料交谈
│   ├── 可提出记录、偏好、提醒等待确认草稿；确认前不写成业务事实
│   ├── 默认平台 AI：沿用已有阿里云聊天接口的单次结构化兼容路径
│   ├── 个人 DeepSeek Key：最多四轮模型调用、八次白名单工具调用
│   └── 无 Key 演示：明确标注的规则模拟，不是真实大模型或联网识图
├── 更直观的生活输入
│   ├── 拍下这一餐：选择照片或主动打开摄像头，核对后发送
│   ├── 活动表达：例如说出开始散步，不擅自补全未提供的运动时长
│   ├── 晨间睡眠：核对入睡和起床时间，按个人时区和分段时间控件填写
│   └── 本机朗读：调用可用的系统语音组件；不可用时继续显示文字
├── 顾问与密钥
│   ├── 本地顾问摘要可参考授权范围内近期会员表达，表达不等于已确认事实
│   ├── 个人 Key 可只用于当前会话，Windows 可主动选择加密保存
│   └── 个人 Key 不随示例数据、源码或发布包分发
└── 为未来扩展保留的部分
    ├── 手机/手环的活动、睡眠、屏幕闲置数据转换协议
    ├── 不是已接入的蓝牙、手环 SDK 或手机系统权限
    └── 屏幕未使用不能被当成实际睡眠测量
```

AI 照片描述不是精确营养测量，不自动推断分量、热量或未提供的医疗事实。
医疗记录可以用于已授权的上下文，不提供诊断、处方或擅自调整用药。
一般云端聊天、平台配额和联网状态仍受实际服务限制；个人 Key 多轮工具调用
可能比单次问答消耗更多模型额度。

本次仅更新桌面 EXE 与 Git 源码，没有发布新的服务器容器。云端新增的顾问
“近期主动表达”摘要上下文，需要日后单独更新服务端才能启用；不能因为源码已
合并便当作现网功能已发布。默认云端聊天草稿兼容现有接口，不以该部署为前提。

## 发布目录与运行

仓库根目录只保留：1.6.0 电脑版演示 ZIP、`application`、参考 UI 图片、
三份原需求 DOCX，以及 `.git`、`.gitattributes`、`.github` 等 Git/GitHub 配置。
旧版桌面包、安卓包和根 README 从当前版本移出，保留在仓库外的可恢复备份，
也仍可从 Git 历史追溯。开发、测试、构建和部署说明保留在 `application` 内。
本机虚拟环境、真实数据库、凭据和临时输出不进入 Git。

程序是 Windows 64 位目录式发行包；应保留完整解压目录。不要用演示数据覆盖
自己的既有数据。ZIP 只带合成示例；现有云端资料仍以阿里云登录账号为准，
本次不修改示例云账号密码、不重新导入云数据。

## 验证范围

本次使用隔离临时目录、合成数据和模拟网络回归，不消耗真实 AI Key 额度、
不读取正式会员资料。完整测试、构建校验、文件哈希及进程启动验收结果将记录
在同目录 `release-1.6.0-validation.md`，并以实际结果为准。

协作者原有 `life-agent-validation.md` 是 2026-09-10 的历史验收记录，
其中 macOS 和真实 API 结果并非本次 Windows 打包实测。尚未完成的真实摄像头、
麦克风、系统朗读硬件端到端检查，以及所有运营商网络的连通性不能据此宣称通过。
Windows 程序未购买代码签名证书；安全扫描无检出也不能保证所有安全软件永不误报。
