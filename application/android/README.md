# 健康生活服务平台 · 安卓版 1.0.2

本版将已有 Python 业务服务和 SQLite 数据库适配为安卓手机应用。手机界面、Python 运行环境、中文 OCR 组件和离线中文语音模型均包含在 APK 中，无需在手机上安装 Python、PyCharm 或 Ollama 才能使用本地管理功能。

## 安装与适用设备

- 适用 Android 7.0 或更高版本的 **64 位 ARM 手机**，也包含 x86_64 测试架构。
- 不支持只有 32 位系统的旧手机，不是 iPhone/iOS 安装包。
- 手机需要启用并更新 Android System WebView；很旧或被停用的系统网页组件可能无法显示现代触屏界面。
- 此次为个人签名的直接安装 APK，未发布到应用商店，不包含支付或收费订阅功能。
- 将 APK 复制到手机后点击安装；若系统询问是否允许当前文件管理器安装应用，按需允许。不要关闭系统安全扫描或添加安全软件排除项。若出现明确的恶意软件告警，请停止安装并保留截图与检测名称。
- 打开后注册会员账号；如需要三角色管理，在首次初始化中创建唯一初始运营员，再由运营员创建顾问账号。没有默认账号/默认密码，也没有“忘记密码”功能。
- 推荐准备至少 600 MB 可用空间，包含安装、Python 初始化、离线模型和一定的附件余量；已有大量资料或导入备份时需要更多空间。

## 数据和设备迁移

APK 是程序安装包，不是会随使用自动变化的数据库。安卓资料保存在应用私有目录，更新同包名、同签名的新版本通常保留资料；**卸载、清除应用数据或手机恢复出厂会删除这些资料**。

迁移步骤：

1. 在旧设备应用中选择“导出完整数据备份”，生成 ZIP；导出包含账号、密码哈希、聊天、记录、提醒、服务、订单、附件原件和报告，不包含 API Key。
2. 把 APK 与这个数据 ZIP 一起复制到新设备。
3. 新手机安装 APK，在空库登录界面选择导入；或用有权限的账号在“我的／数据备份”中导入。
4. 导入会校验格式、数据库结构、完整性和校验和，替换前自动保留本机旧库安全备份。导入后重新使用原账号密码登录；密钥需再次输入。
5. 核对历史记录和附件后，才决定是否清理旧设备。不要把安装 APK 本身当作已经导出了历史记录。

电脑 1.0.1 与安卓 1.0.2 共用 SQLite schema v4 和数据备份格式。通过应用生成的数据 ZIP 迁移，不直接复制运行中的 `app.db`，也不要把 Windows 程序发布 ZIP 当作数据备份。全库备份含所有账号资料，应作为敏感文件妥善保管，不上传公共网盘链接。备份 ZIP 没有额外加密；密码为 Argon2id 哈希，但健康资料正文和聊天不是加密数据库。

全库操作权限：已有运营员时只允许运营员；无运营员且仅有一个账号时允许该账号本人；首次空库允许登录前导入，避免普通会员取走他人资料。

## AI 与网络

- **Ollama Cloud**：用户自己获取并输入 API Key，手动获取账号可用模型。优先使用用户账号可用额度，免费额度、模型资格以官网为准，本应用不承诺任何服务永久免费。
- **DeepSeek**：固定 `deepseek-v4-flash`，用户自己输入密钥；费用或额度由 DeepSeek 账号决定，不预置他人密钥。
- **局域网 Ollama**：不自动检测；手动填写同一可信局域网电脑的 IP 和模型。手机的 `127.0.0.1` 指手机本身，不是你的电脑。不要向公网开放 Ollama；未加密的局域网 HTTP 仅适合可信网络。
- API Key 仅保存于运行内存，退出登录或结束应用后需要重新填写，不写进数据库、备份或应用日志。
- 普通聊天只提交对话上下文。生活整理或顾问摘要会在明确提示并主动确认后提交相应档案/生活/服务资料。AI 建议先成为草稿，确认前不会自动改写事实。
- 未提供真实云密钥的测试不等同实际云生成已验证；云端可能发生额度不足、超时或模型变化，会显示错误提示。

官方入口：[Ollama 密钥](https://ollama.com/settings/keys)、[DeepSeek 密钥](https://platform.deepseek.com/api_keys)、[DeepSeek 额度](https://platform.deepseek.com/usage)、[DeepSeek 文档](https://api-docs.deepseek.com/zh-cn/)。

## 时间、录音、OCR 与提醒

- 时间输入与显示固定为 **北京时间 UTC+8**，无需填写时区；内部保留带时区的时间语义及 UTC 存储，搬到其他时区不会把历史记录统一平移。
- 麦克风只在点击语音输入后请求权限；切到后台、退出或手动停止时停止录音。识别文字先回填输入框，不会自动发送到 AI。
- 语音与图片文字识别可在本机进行，首次使用无需下载中文模型。OCR 会处理照片 EXIF 方向；识别仍可能错误，报告需要本人逐项核对。
- PDF 支持原件预览和翻页、文字层提取；加密或损坏文件不支持。扫描版 PDF 没有文字层时，可先导出相应页面图片再进行图片 OCR。
- 当前提醒是应用内事项展示，**没有手机后台闹钟或关闭应用后的系统通知**，不能用作重要事项的唯一提醒工具。
- 模拟商品订单没有真实扣款、支付、物流或医疗服务。

## 隐私边界

不申请通讯录、定位、短信或全盘文件权限；文件通过系统选择器由用户选择。应用数据库不参与系统自动云备份。WebView 仅加载安装包中的白名单界面资源，不允许任意网页获得本地接口。

中文 OCR 使用 Google ML Kit 的 bundled 组件。其输入图片、文字与识别结果在设备上处理，不由该组件上传这些原文；但 SDK 可能联网发送设备/应用信息、每安装标识、性能和调用/错误诊断统计，因此本应用不是“绝不自动联网”的隔离软件。详见 [ML Kit 隐私说明](https://developers.google.com/ml-kit/terms#privacy) 和 [Android 数据披露](https://developers.google.com/ml-kit/android-data-disclosure)。应用内已提示这一点。

## 检查范围与真机验收

随交付附上实际自动检查结果。源码测试、手机尺寸浏览器联调、签名与 APK 校验只能覆盖各自范围，**不等同在你的手机上逐项实际验证**。

本机安卓 SDK、JDK 和 Python 已具备。现有模拟器缺少硬件加速，软件模式在安卓启动前崩溃；目前没有连接可用安卓真机。设备侧 7 项测试已经写好并编译测试包，但没有设备时不会标记为通过。

真机需要验收：安装/首次启动、账号登录、应用退出重开、编辑北京日期时间、麦克风允许/拒绝/停止/切后台、中文照片 OCR（含旋转）、PDF 预览、系统文件导入/导出、Windows 数据往返迁移、系统回收文件选择中的应用后重试，以及用户自己密钥的一次云端对话。

## 开发者重建

- Java 21；Gradle 8.13；AGP 8.13.2；Chaquopy 17.0.0；Python 3.13。
- Android compileSdk 36 / extension 19 / build-tools 36.1.0 / minSdk 24。
- 从项目运行 `android/build-android.ps1 -Variant Release`。路径可通过脚本参数修改，Python 构建解释器应为 3.13。
- Python 直接依赖和安卓原生依赖在 `app/build.gradle` 中固定。测试服务 `tools/android_ui_server.py` 不进入 APK，不可对公网运行。
- 发布签名密钥在项目 `packaging/private-android-signing` 中，**不可随 APK 分发**。密码由 Windows 当前用户的 DPAPI 加密；要保留该文件夹和可解密的原 Windows 用户环境。未来覆盖升级必须使用同一签名，不要随意重新生成；在重装电脑前另行完成安全的签名凭据备份。

技术方案依据：[Chaquopy 官方构建说明](https://chaquo.com/chaquopy/doc/current/android.html)、[Android 本地 WebView 内容方案](https://developer.android.com/develop/ui/views/layout/webapps/load-local-content)。
