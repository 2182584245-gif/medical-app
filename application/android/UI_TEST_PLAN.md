# 安卓手机界面检查清单

本文件是可重复执行的检查清单，不代表所有项目已经在真机通过。最终执行结果以本次发布的检查报告和测试输出为准。

## 界面与数据边界

- 本地 `index.html + app.css + app.js`，中文触屏界面；页面本身没有外部脚本、字体、图片或统计网络依赖。
- 会员底部导航：今日、记录、AI 助手、服务、我的；顾问和运营员底部导航：工作台、会员、服务任务、AI 助手、我的。
- 所有账号和 AI 文本经 `textContent` / 文本节点显示，不把用户内容作为 HTML 或脚本执行。
- API Key 和密码不写入 `localStorage`、`sessionStorage`、网页数据库或 URL；会话密钥只交给 Python 内存密钥管理。
- 普通对话发送前显示上下文说明；生活整理和顾问摘要必须勾选本次资料发送授权，再主动点击生成。
- 角色权限由 Python 服务逐次核验，不依赖页面按钮隐藏。
- 日期时间控件使用原生 `date` / `datetime-local`；保存 datetime 时明确附上 `+08:00`。显示使用时间戳转换到固定 UTC+8，不依赖手机当前时区。
- Android 返回键优先关闭表单弹层、其次返回当前角色首页，首页交给系统处理退出。
- “完整备份”有全部账号及附件说明；导入有覆盖、不合并、自动旧库安全备份和重登警告。

## APK 与设备专项检查

这些项目不能仅用网页测试替代：

1. 安装、首次启动、数据库初始化、关闭重开与原版本更新保留数据。
2. 系统日期/时间选择器可用；系统时区设为非中国时仍以北京时间保存和显示。
3. 图片/PDF 选择与取消；原生预览和 PDF 翻页；离线中文 OCR 无网可执行。
4. 麦克风授权/拒绝；离线语音启动、部分文本、累计结果、停止、超时与切后台停止。累计文字应替换录音区域，不能反复追加重复片段。
5. SAF 系统文件选择器导出附件、导出备份、取消操作、导入有效备份和拒绝损坏备份；不申请全盘存储权限。
6. 安卓→安卓、Windows→安卓、安卓→Windows 的备份格式互通与历史数量核验。
7. 云端真实调用需要用户有效 Key 及网络；未执行真实收费请求时不得标记“已通过真实云调用”。
8. 局域网 Ollama 需用户明确提供实际电脑地址与服务配置；无服务时检查错误说明，不自动扫描局域网。
9. 真机厂商电源管理、键盘、WebView 版本、麦克风质量和网络限制需要对应设备验证，不宣称“任何手机万无一失”。
