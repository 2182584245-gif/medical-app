# 离线与分页同步契约（桌面 1.4.0 / 协议 2）

此功能默认以云端为主。离线登录与待提交功能须在登录页明确选择启用，不能代替首次在线登录，也不会创建离线账号。

## 登录与有效期

- 在线登录返回不含秘密的 `offline_lease`：当前用户、角色、服务实例标识、签发时间与到期时间。有效期取 12 小时、当前在线会话到期、顾问任期到期三者最早值；因此当前服务会话若为 2 小时，离线也最多 2 小时。
- 只有成功的 HTTPS 登录可以登记离线凭据。Windows 当前用户 DPAPI 加密的文件中保存 Argon2 验证值及安全账号资料；不保存明文密码或 bearer token。离线登录还必须找到与这份授权完全匹配的完整加密镜像。
- 离线密码连续错误 5 次暂锁 5 分钟；租约到期、身份或服务实例不匹配、当前会话检测到时间回退，以及持久化高水位时间检测到回退，均拒绝访问。
- 同一运行进程恢复网络后先调用 `/auth/me`，再重放。跨重启离线会话没有在线 token；只读连接探测成功后锁定离线访问，要求用户在线输入密码。连接探测本身绝不是身份认证。
- 不能声称在断网时获知远端撤权。远端撤权/任期变更在恢复连接时核验；断网期间只在此前授权的绝对期限内访问。拥有当前 Windows 用户或管理员权限的人不是此本机加密机制可以隔离的对手；Windows DPAPI 也不是防管理员篡改的可信时钟。

## 待提交队列

支持会员生活记录新增、提醒新增/更新/暂停/恢复、预约申请、本人档案更新和本人偏好更新。账号管理、支付、删除、文件上传及其他方法必须在线。离线不能扩大 AI/天气资料分享同意；排队的撤回同意立即成为本机禁止分享条件，其他设备须等待云端确认。

`QueuedOperation` 只表示本机加密保存的意图，不是云端记录 ID。UI 必须显示“待提交”，不能显示云端保存成功或使用虚构业务 ID。

- 队列以服务地址 + 服务实例 + 用户分区，以 DPAPI 加密保存；上限 200 项，每项 256 KiB。队列不调用任何本地业务数据库服务。
- 重放固定 UUID，使用既有 `rpc_requests` 事务日志。正常 API 写入共享数据库写锁；修改类意图比较原资源内容摘要，冲突返回 409，不默默覆盖。新增意图仍由正常业务验证器及当前角色权限检查。
- `queued` 与 `uncertain` 自动用原 UUID 重放。`uncertain` 不允许丢弃或换 UUID，因为云端可能已经执行。
- 只有服务器明确返回“原资源版本已变化”且此前并非结果不明的项，才属于可重新提交的冲突。权限范围变化导致的幂等日志冲突、未知 409，或原 `uncertain` 项后来出现 422/404，均仍为 `uncertain`，不能借重新生成 UUID 重复创建。
- `conflict` / `rejected` 保留本机意图供用户查看。在线且有最新完整镜像时，用户确认的 `rebase_pending` 才基于当前资源版本创建新 UUID；`discard_pending` 仅移除本机项，不修改云端。
- 外部管理员批量导入不属于普通 API 写锁保护范围，须按运维工具维护窗口停止写入，再重新登录/同步。

## 分页、附件与范围

登录响应 `sync_protocol=2` 启用 `get_sync_manifest`、`get_sync_page`、`get_file_chunk`。旧客户端/旧服务继续使用协议 1，不把旧协议容量限制伪装成完整同步。

协议 2 同步档案、偏好、全部本人生活记录与提醒、全部本人会话与消息、服务摘要、当前角色可见预约/会员/顾问/工作统计、上门记录，以及本人文件和报告详情、本人会话附件。顾问上门记录额外要求仍有有效会员绑定。账号凭据、会话 token、API key、支付或权限写入不在离线镜像接口范围。

每页最多 100 项、约 512 KiB 内容，每个附件块 64 KiB。每页校验内容版本；客户端检查顺序、计数、资源摘要，结束前再次核对清单。附件核对身份、文件 ID、总大小、偏移及 SHA-256，完整验证后才以 DPAPI 密文保存；使用哈希文件名，绝不执行附件、按原始文件名落盘或使用服务器路径。

只有连接失败、超时或服务暂不可用允许继续显示仍在授权期内的旧镜像。分页 409/422/404、格式或完整性不符，包括最后清单变化，都会锁定镜像并发出清除展示的授权失效信号；不能当成普通断网继续显示可能已解绑的资料。

8 MiB 仍是单次同步 HTTP 响应安全边界，不是全账号上限。已用 1,005 条合成记录、超过 8 MiB 的内容验证完整分页与加密镜像恢复。桌面另设明确设备预算：结构化镜像最多 250 MiB、当前附件集合最多 250 MiB、单文件最多 15 MiB、单条同步记录最多 512 KiB。达到预算则拒绝发布不完整镜像，不宣称无限容量。

当前实现按资源重新计算内容版本，属于有完整性核验的分页全量同步，不是数据库增量 CDC。超大型资源会增加服务器扫描及内存成本；扩大至大量企业数据前需要另行设计有索引的变更日志与流式持久层。购物/支付是否在云端使用须遵循独立业务 UI 的连接范围，不因新增分页而自动改变。

## 桌面集成接口

- `CloudAPIClient(..., offline_store=OfflineAccessStore(path))`
- `login(username, password, *, allow_offline=False, remember_offline=False)`
- `CloudSyncService.start(actor_id, expected_server_instance_id=None, *, role_code=None)`
- `state()` 包含 `offline_expires_at`, `pending_count`, `conflict_count`, `offline_editable`。
- `reauthentication_required(str)`、`outbox_changed(dict)` 与既有授权/快照信号由主窗口消费。
- `pending_operations()` 只给摘要；`get_pending(id)` 只给本项编辑内容；`discard_pending(id)`、`rebase_pending(id, patch=None)`、`sync_now()` 按上述规则操作。
- `SyncedRemoteService(remote, sync)` 保持原服务签名；未知读请求仍走云端，未知/高权限写入绝不落本地库。

## 验证边界

测试只使用隔离目录、合成账号、模拟网络与本机测试数据库，不访问用户现用缓存、真实 AI key 或线上数据库。Linux 后端导入不依赖 Qt，DPAPI 仅由 Windows 桌面调用。本轮未增加 PostgreSQL 表或运行云端 DDL。
