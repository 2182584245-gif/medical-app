# 本地测试归档

本目录用于保存 1.7.0 电脑版相关的历史测试资料。它们是历史验证记录，不代表本次重新执行或通过了所有测试。

- `1.7.0/独立测试`：客户端、离线、权限、用户流程、演示资料和发布包等测试工作目录。
- `1.7.0/后端测试报告`：原来散落在 D 盘根目录的 XML 报告。
- `1.7.0/演示数据`：虚构演示账号和商品等测试种子。
- `1.7.0/版本验收`：1.7.0 各轮构建、界面、登录修复的测试和验收记录。
- `整理记录`：本次迁移、清理及完整性核验清单。
- `startup`：之后由启动检查工具新建的隔离测试目录。

资料按原目录名保存，避免不同测试轮次中的同名文件互相覆盖。

## 隐私和 Git

原始测试工作目录可能含数据库、账户信息、日志或本机加密配置。除本说明和 `.gitignore` 外，本目录内容默认被 Git 忽略，只保存在本地；不要强制加入 Git 或直接公开上传。

没有删除或移动原有 `application/tests` 测试源码。本目录仅归档仓库外的历史测试资料。最新部署资料与私人回退备份已于 2026-09-28 统一迁入同一仓库下的 `本地维护/部署资料` 和 `本地维护/回退备份`，不作为普通测试缓存删除。较早清理记录中的原位置仅表示当时状态，当前路径请查看 `本地维护/归档记录/路径映射.json`。
