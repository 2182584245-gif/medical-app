# 凡思鸿蒙手机版

本目录是凡思 HarmonyOS 手机客户端。1.6.18（11870）用鸿蒙 ArkWeb 加载随安装包发布的安卓页面资源，涵盖五个主页面、子页面和首次见面动画。三个认证页面沿用已验收的鸿蒙 11868 排版。相册、拍照、录音、提醒、系统分享、更新和云端通信由鸿蒙客户端处理。

## 运行

以 HarmonyOS 7.0.0 和配套 SDK 26.0.0 为开发和验收基准，最低兼容 HarmonyOS 6.1.1（API 24）。在 DevEco Studio 26.0.0 Release 中同步项目后选中 `entry` 和手机模拟器，点击运行。命令行可运行 `hvigorw assembleHap -p product=default`。从 11866 开始，包名为 com.fawnsee.health.mobile，对应华为开发者中心的「凡思」。旧 11865 开发包中的离线草稿留在原安装中。

默认连接和安卓版相同的阿里云服务。用户可以在助手页体验图文对话，通过底部“记录”进入会员登录。同一会员可在两个客户端读取同一条云端记录。供隔离测试的账号和服务地址由验收环境提供。

## 页面和验证

- `entry/src/main/resources/rawfile/fawnsee-web` 保存网页入口、样式、动画和图片。
- `entry/src/main/ets/pages/Index.ets` 处理本机隐私同意，`HybridWeb.ets` 承载业务页面和系统返回。首次同意隐私政策后，系统依次处理通知、麦克风和日历授权。拍照和选图分别交给系统相机和图库。
- `entry/src/main/ets/services` 处理云端请求、设备凭据、照片、语音、提醒和本机数据。
- [本轮非 AI 功能对照](验收/11870/非AI功能对照.md) 列出已有操作证据、服务限制和设备待验项。
- [记录复测说明](tests/records.md) 提供可重复运行的七类记录和离线检查。
- [11867 验收](验收/11867.md) 记录系统分享、局部加载失败和键盘布局的验证结果。
