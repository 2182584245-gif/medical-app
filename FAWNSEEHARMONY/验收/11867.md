# 凡思鸿蒙 11867

1.6.15-try1.2 的开发与验收基准为 HarmonyOS 7.0.0，配套 SDK 为 26.0.0。安装包使用华为登记包名 `com.fawnsee.health.mobile`，编译 SDK 为 26.0.0.105，最低兼容 HarmonyOS 6.1.1（API 24）。[华为版本适配说明](https://developer.huawei.com/consumer/cn/doc/harmonyos-releases/upgrade-adaptation/)

## 功能验证

华为官方手机模拟器 `Fawnsee_Harmony7_QA` 实际运行 HarmonyOS 7.0.0.107 SP8（API 26），屏幕为 1320 × 2232。11867 的交付 HAP 安装并启动后进入「智能助手」。打开系统键盘时，标题保持在 y=117–321，输入栏底边与键盘顶边同为 y=1266；收起键盘，输入栏、消息区和五项底部导航全部复位。

| 操作 | 实际结果 |
| --- | --- |
| 打开社区帖或知识文章，点分享 | 系统面板显示对应标题、华为分享、复制等选项。文章取消后转发次数保持 0，在面板选择复制后变为 1，详情中的独立复制按钮也可使用 |
| 「我的」页面单个统计请求失败，再点该项重试 | 姓名、会员状态、5 条生活记录以及社区发表 0 条仍然可见。失败项显示「—」和重试入口，重试后该项恢复为 7 天 |
| 帖子评论加载失败，或文章的互动和评论同时失败 | 正文和分享仍能使用；点「重试互动」和「重试评论」可分别恢复对应的区域。权限被拒时会清除详情 |
| 助手历史、欢迎语或偏好加载失败 | 历史重试保留输入和附件，欢迎语失败仍可读取对话。偏好未取回时可继续输入，发送前会重新获取，以用户的实际授权设置为准 |
| 在同一台 1320 × 2232 的 API 24 手机模拟器对比 11866 和 11867 | 旧版弹出键盘时标题移出屏幕。新版保持标题在原位，输入栏下边缘与软键盘上边缘同为 y=1266，收起键盘后五项导航恢复 |

在鸿蒙 7.0.0 模拟器中，社区与文章的 11 个界面检查点全部通过，涵盖系统面板、取消、两种复制操作、正文保留及分区重试。「我的」页另行复现成长统计失败并点按恢复，生活记录仍显示 5 条，社区发表仍显示 0 条。以上故障和分享场景在 6.1.1 兼容模拟器上也已复验。

分享和故障场景使用独立测试包，加载实际页面和系统分享面板，以合成数据控制接口返回。分享操作选择取消或复制。键盘验收使用实际交付 HAP。助手历史、欢迎语和偏好故障由自动化测试覆盖。
