# 凡思双端 11870 验收

安卓版本为 1.6.17-try1.2，鸿蒙版本为 1.6.18。两端均使用同一会员系统和云端生活记录。线上 AI 专项 30 组中 29 组通过，跨日生活档案重新总结未通过。线上用例运行实际客户端业务逻辑，连接阿里云与 DeepSeek。界面点击和系统授权另在模拟器实测。

| 检查项 | 实际操作与结果 |
| --- | --- |
| 首次启动与引导 | 鸿蒙 7 模拟器可在联网前打开本地隐私政策。新建普通账号后，资料引导可从中断位置继续。开启自动登录后重启，继续使用同一测试账号。 |
| 系统权限 | 鸿蒙同意首次隐私说明后依次出现通知、麦克风、日历三个系统提示。系统相机和相册按次交付用户指定的文件。安卓 16 依次询问麦克风、相机、通知，处理完留在应用，拒绝后访客仍能打开系统选图器。安卓精确闹钟及安装下载的 APK 需要按系统的特殊授权流程处理。 |
| 附件与记录 | 鸿蒙使用系统文件选择器取得合成文本文件，核对内容与原文件一致。在 AI 页发送后观察到了流式返回。鸿蒙 7 模拟器实点图库、发送测试餐照，在草稿预览图片，确认保存后从记录列表重开，使用口语修改原条目后再次打开，云端仍为原记录且原图字节完全一致。 |
| AI 对话与初次使用 | 鸿蒙 7 模拟器验证了聊天设置的保存与恢复、输出中停止后立刻发送新问题、对话重开，以及首次使用教学。明确说“无需记录”时正常对话，云端未产生草稿或写入。点击每日和每周回顾均返回了已有记录。 |
| 子记录助手 | 真实云端用例验证了口语补答、必填与选填不同处理、前后矛盾先请确认、多份草稿搜索切换，以及给同一旧条目补上不同照片、相同照片去重。七类核对卡的字段名、顺序及确认操作由组件回归验证。 |
| 生活档案 | 十一类档案可以进入；在包含两天测试资料的账号上多次执行“重新总结”，线上版本 V6 仍有作业失败，最后一次鸿蒙界面复测也返回暂不可用，本项未通过。 |
| 七类手动记录 | 鸿蒙模拟器中七类逐一新增、修改、重开并从云端复核。饮水记录从详情确认删除后，云端按原编号查无对应记录。 |
| 健康资料和各类日常功能 | 七类记录、提醒、成长统计、阅读、社区、备份入口及系统差异见[非 AI 功能对照](非AI功能对照.md)。支付与付费开通未实际执行，个人云备份和恢复尚未开放。实体鸿蒙 7 手机的相机成像、锁屏提醒及经华为市场下载更新，仍待相应环境验收。 |
| 自动化 | 鸿蒙公开源码的 62 项客户端测试通过，安卓本轮原生权限策略 21 项通过，新后端 V6 的 227 项隔离回归通过。另从公开后端源码运行本轮注册／迁移／AI 专项测试，38 项通过，1 项需要独立 PostgreSQL 测试环境而跳过。 |
| 安装 | GitHub Releases 提供使用正式 Android 证书签名的 APK，以及由公开鸿蒙源码构建的未签名 HAP 和 APP。鸿蒙 HAP 需要签名并匹配设备后安装。 |

用来验证云端及鸿蒙界面的专用账号已完成注销，使用原凭据重新登录时均被拒绝。最终云端存活与就绪检查均成功。

公开源码沿用仓库原有阅读资料范围。安装包校验值列在对应 Release，原始测试账号、系统记录和设备描述文件由项目方本地保管。
