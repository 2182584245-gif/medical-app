# 凡思鸿蒙 11865 功能验收摘要

| 环境 | 操作 | 结果 |
| --- | --- | --- |
| 鸿蒙 API 24 模拟器，正式后端 | 在助手里发送餐照并要求记录，口语补充时间，核对后保存 | 草稿显示原图和表单字段。保存后可在同一条晚餐记录中打开原图，原文件摘要与上传前一致 |
| 鸿蒙模拟器，正式后端 | 给旧记录追加标签图片，再用另一张标签修改热量 | 同一条记录保留原照片和备注，追加的标签可打开原图。仅用于识别的第三张图未加入记录 |
| 鸿蒙模拟器，正式后端 | 饮水缺量、口语补答、拒绝提供必填项，两份草稿来回切换 | 整杯 350 毫升能填回原草稿。拒绝提供水量时提示无法确认。另一份饮食草稿保留原图 |
| 鸿蒙模拟器，正式后端 | 先说午餐，又说今晚八点吃晚餐 | 保留原图、时间和已有字段，向用户核对餐次。明确以晚餐为准后可以确认 |
| 鸿蒙模拟器 | 在后台和锁屏等待生活提醒 | 系统投递日历提醒。修改同一条提醒沿用原编号，关闭后清理应用创建的日程 |
| 鸿蒙模拟器 | 打开更新页，查询市场版本 | 能读取本机 11865。市场查询失败时可重试。此次未取得更高版本做覆盖升级 |
| Mate 40，安卓版 11864 | 短信登录相同会员，查看鸿蒙端保存的晚餐，启动相机、锁屏等待提醒 | 能查看同一条记录和餐照。拍摄后回显缩略图。锁屏通知比设定时间晚约 42 秒 |

原生鸿蒙验收设备为模拟器。普通客户安装、纯鸿蒙手机的摄像头、长时间省电后的提醒和市场更新安装仍需在相应设备与分发渠道验证。
