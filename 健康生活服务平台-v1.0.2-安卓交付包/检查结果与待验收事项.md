## 本轮发现后修正的问题

- 安卓新系统的返回手势适配。
- 旧安卓系统不支持的集合/字符串 API 用法。
- 竖拍、镜像照片的 EXIF 方向处理；使用 AndroidX 兼容读取组件，避开旧系统读取实现的已知风险。
- OCR 超时后异步任务尚未结束就释放图片资源的问题。
- 录音分段结果错误地使停止按钮消失、后台取消准备可能重新开启录音、停止时丢失尾句的问题。
- 旧界面退出时的异步清理可能影响新登录会话的问题。
- PDF/图片预览生命周期和临时文件清理。
- 系统回收应用后文件选择结果丢失时的中断提示。
- 列表节点显示成对象字符串、部分字段选项/订单状态不一致、窄屏卡片错位。
- 尚未保存的云密钥跨服务残留，以及密码前后空格被界面自动去掉的问题。
